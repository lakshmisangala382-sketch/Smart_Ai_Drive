# 🚗 Smart AI Drive System

A Java-based Smart AI Drive System that simulates an intelligent in-vehicle assistant. The application provides multiple smart features to improve driving safety, convenience, and vehicle management.

🟢 **Current Version:** v1.0

✅ Console Application Completed

✅ Uploaded to GitHub

🔄 Currently Working On: JavaFX Graphical User Interface (GUI)

# ✨ Features

- 🎤 AI Voice Assistant
- 🔊 AI Voice Selection
- 🌐 Multilingual Voice Assistant
- 🚗 Vehicle Health Assistant
- ⛽ Fuel & Level Assistant
- 🔧 Maintenance Assistant
- 🚨 Emergency SOS
- 🗺️ Navigation Assistant
- ⚠️ Road Damage Alert
- 📊 Smart Monitoring
- 🔍 AI Vehicle Troubleshooting
- 👤 User & Vehicle Profile

# ▶️ How to Run

1. Clone this repository.
2. Open the project in Eclipse IDE.
3. Run `SmartAIDrive.java`.
4. Select any feature from the console menu.
